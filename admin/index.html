Edition details

Edition color palette

Choose colors for this month. These will update the public game only when you publish.

Creature appearance chances

Secret choices (such as fighting a Gnoll or Ogre) roll once per run. Individual character appearances are editable in Backgrounds & Characters. A Legendary prize is earned only when a player follows its winning story route, not from a separate reward roll.

Use + New Month to start blank or copy the Autumn structure. Save, Preview, Approve, then explicitly Publish when ready.

Player-facing text

Edit opening text, question labels, prize reveal, retry instructions, menu labels, inventory, Guild and map copy. Story questions and ending descriptions remain in their own tabs.
